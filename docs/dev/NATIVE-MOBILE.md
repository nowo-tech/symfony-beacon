# Mobile / PWA

Use the **Progressive Web App** (`nowo-tech/pwa-bundle`) for installable mobile access to the same Twig UI.

## Hotwire Native / Symfony UX Native — deferred

Hotwire Native (`symfony/ux-native` + `symfony/ux-turbo`) is **not** shipped in this repository today.

It remains a **future roadmap item** (see [ROADMAP.md](../ROADMAP.md) — Phase 6+ deferred). Do not reintroduce the packages until that work is explicitly prioritized and the constitution is amended.

Historical design notes: [`specs/008-ux-native/`](../../specs/008-ux-native/) (**Status: Deferred / Future**).
